Para explorar

  1. Con el ejemplo del libro, predice el bin del pico y compruébalo. Después cambia P a 200 s: ¿dónde quedará?
  2. Duplica la captura (N = 7200). ¿Qué les pasa a Δf, al bin del pico y a cuánto destaca el pico sobre el fondo?
  3. Sube el jitter poco a poco. ¿Qué le pasa al pico? ¿Qué armónicos desaparecen primero?
  4. Pon P = 280 s con N = 3600. ¿Por qué el pico se reparte entre dos bins?
Seguridad: una conexión breve y casi perfectamente periódica es una firma de actividad automatizada, como un malware que "llama a casa" a su servidor de control remoto (C2), muy distinta del patrón irregular del tráfico humano. Como esta detección es tan sencilla, muchas herramientas de control remoto agregan jitter: el pico se ensancha y baja, y el analista necesita observar más tiempo. Ojo: un pico también puede ser un proceso legítimo programado, como un respaldo; amerita investigación, no es una prueba.
